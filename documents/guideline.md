## Teams（利用規約）

https://kiyaku.jp/ を参考に作成。

### teams.md の更新

1. `teams.md` をコピーしたものを制定日にリネーム。（ex. 20241201.md）
2. `teams.md` を編集し、利用規約を更新。
3. `teams.md` の内容を HTML に変更し、`teams.html` の内容も更新。
4. Firebase Storage に `teams.md` と `teams.html` をコンソールからアップロード。
